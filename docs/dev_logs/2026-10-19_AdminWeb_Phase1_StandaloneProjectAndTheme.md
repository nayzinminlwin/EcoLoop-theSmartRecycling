## 4. Technical Decisions & Deviations

- **Node version relaxation:** Plan specifies `>=22.14.0 <23` but installed Node is v24.11.1. The `engines` field in `package.json` was widened to `>=22.14.0 <25` to prevent `npm install` from erroring with an incompatible engine warning, while keeping the `npm` engine at `>=10.9.2 <12` (npm 11.6.2 is installed). This is a minimal, justified deviation — no dependency or behavior changes.
- **No `tsconfig.json` added:** Per plan section 4, the explicit `tsc` CLI flags in `npm run check` replace a config file. No additional config file was created.
- **No `vite.config.ts` added:** Vite's zero-config default handles the `index.html` + `src/main.tsx` entry and TSX transform without a config file in this phase.
- **Inline icon in `main.tsx`:** The `Icon` type in `main.tsx` is scoped to only `"leaf"` (the only icon needed for the Brand mark in the bootstrap preview), avoiding unused-parameter TypeScript errors from a full icon union that isn't used yet.
- **`import * as React`:** Used consistently so classic JSX transform has a real `React` binding without needing the automatic JSX runtime configured.
