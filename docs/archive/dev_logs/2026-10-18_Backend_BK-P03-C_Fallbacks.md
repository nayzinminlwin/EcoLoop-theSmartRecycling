## Implementation notes

- Crop metadata retains source object ID, source box, padded crop box, dimensions, and padding configuration.
- Crop fallback responses must resolve exactly one object and may only label the existing candidate.
- Full-image fallback returns bounded distinct inventory entries and does not infer an empty batch from an empty list.
- Unsupported labels, malformed schema, identity mismatch, invalid counts and invalid normalized geometry return explicit unresolved reasons.
- Gemini response validation does not treat provider confidence or valid JSON alone as acceptance.
